Detailed Description

HTTP transport helpers based on libcurl.

Implements authenticated GitHub API requests and response handling.

Perform an authenticated HTTP request using libcurl.

Parameters
[in]urlAbsolute request URL, no longer than MAX_URL_LENGHT.
[in]auth_tokenGitHub API token used for the Authorization header.
[in]url_methodHTTP method to perform.
[in]data_to_postRequest body for POST, otherwise NULL.
[in]content_typeRequest content type.
[in]timeoutRequest timeout in milliseconds.
[in]b_insecureIf true, disable TLS peer and host verification.
Returns
Heap-allocated response body on a successful 2xx response; the caller owns the result and must free it. Returns NULL on invalid input, transport failure, or non-2xx response.
